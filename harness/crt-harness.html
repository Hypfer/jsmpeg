CRT COMPOSITOR — tuning harness

Synthetic "video" = moving bands + a live frame counter, so a frozen picture is obvious. No-signal = colour-bar test card; the VALETUDO channel indicator pops up when the stream starts.

signal state

Stall = connection alive, snow creeps but stays snow. Cut signal = snow saturates, holds a beat, then hard-cuts to the colour-bar test card.

tuning knobs
manual noise override

Freeze the noise level to inspect the look regardless of the timer.

present rate (proves rate-independence)

Noise level is wall-clock driven, so the ramp reaches full in the same real time at any rate.

renderer

Canvas2D is the fallback for weak / blocklisted GPUs. Snow = pre-baked streak-noise tiles + phosphor blend (no per-pixel work per frame).
